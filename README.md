# Inventario

App web de un solo archivo para llevar el inventario de un negocio familiar sobre un Excel guardado
en OneDrive personal. Se publica con GitHub Pages; no tiene servidor ni costos.

- **Usar:** abrir la página de GitHub Pages e iniciar sesión con la cuenta de Microsoft.
- **Versión publicada:** Ajustes → Acerca de. Cambios en [CHANGELOG.md](CHANGELOG.md).
- **Cómo está hecha:** [docs/DISENO.md](docs/DISENO.md).
- **Compilar:** `npm install` y luego `npm run build` (genera `index.html`).

Este repositorio es público: nunca subir el Excel real, tokens ni datos del negocio.
`test/prueba.xlsx` tiene datos inventados.
